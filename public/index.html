Endpoints da API

POST
/api/quote
Inicia uma cotação automática. Retorna imediatamente e processa em background. Ideal para integração.
{
  // Headers obrigatórios:
  "x-api-key": "sua-api-key",

  // Body (JSON):
  "requestId":  "SOLIC-001",          // ID da solicitação no seu sistema
  "name":       "Nespresso Essenza",  // Nome do produto (opcional se tiver links)
  "links":      ["https://www.mercadolivre.com.br/..."], // URLs (opcional)
  "webhookUrl": "https://seu-sistema.com/webhook",       // Recebe o resultado pronto
  "metadata":   { "solicitante": "Beatriz", "dept": "TI" } // Dados livres
}
// Resposta imediata (202 Accepted):
{
  "quotationId": "uuid-gerado",
  "status": "processing",
  "pollUrl": "/api/quote/uuid-gerado"
}
// Payload do webhook / resultado final:
{
  "quotationId": "...",
  "requestId":   "SOLIC-001",
  "status":      "done",
  "productName": "Nespresso Essenza Mini Preta",
  "metadata":    { "solicitante": "Beatriz" },
  "summary": {
    "bestPrice":   289.00,
    "bestStore":   "Mercado Livre",
    "bestUrl":     "https://...",
    "savings":     64.00,
    "totalOffers": 5
  },
  "results": [
    {
      "store":      "Mercado Livre",
      "price":      289.00,
      "oldPrice":   349.00,
      "freeShip":   true,
      "freight":    "Frete grátis",
      "rating":     4.8,
      "condition":  "new",
      "url":        "https://...",
      "thumbnail":  "https://..."
    }
  ],
  "errors": []
}
GET
/api/quote/:id
Consulta resultado de uma cotação por ID (polling alternativo ao webhook).
GET
/api/quote?limit=20
Lista as últimas cotações (para dashboard/auditoria).
POST
/api/search
Busca síncrona (aguarda resultado). Use para testes ou integrações simples.
GET
/api/health
Health check — verifica se a API está rodando.
